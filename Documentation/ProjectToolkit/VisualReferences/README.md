# Project Toolkit Visual References

This directory contains design references used while specifying and reviewing Meganeura Project Toolkit.

These files are development inputs, not package assets. Keep them outside `Assets/` and `Packages/com.meganeura.project-toolkit/` so Unity does not import them and they are not included accidentally when distributing the package.

## Usage Rules

- The numbered Project Toolkit spec remains the source of truth.
- Use each image only for the aspects explicitly listed by that spec.
- Do not infer unlisted behavior from a screenshot.
- Do not reproduce exact artwork, icons, palette values, branding, text, dimensions, or proprietary implementation.
- Build an original Meganeura visual language compatible with Unity's light and dark themes.
- Do not move third-party screenshots into the distributable package.
- Before public release, review whether these development references should remain in the repository.

## Source

The files under `vFolders2/` are screenshots supplied by the project owner from the public marketing material for **vFolders 2** by kubacho lab:

<https://assetstore.unity.com/packages/tools/utilities/vfolders-2-255470>

They are retained only as internal design references. Ownership remains with their respective creator.
